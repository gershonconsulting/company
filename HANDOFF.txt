1. WHAT THIS REPO IS
----------------------------------------------------------------
Product / site name : Company by Gershon.AI (Streak-based CRM administration)
Live URL            : https://company.gershoncrm.com
What it does        : Reads the "GC Pipeline" from Streak and shows pipeline
                      analytics (pages: today, analysis, objectives, swot,
                      values, warnings, reports, settings). Sends two weekly
                      emails every Monday: the Weekly Pipeline Report and
                      the Sales Weekly report (via Resend).
                      Streak/Resend keys and report addresses are stored in
                      the SETTINGS KV namespace, edited on /settings.
Who uses it         : Olivier and the Gershon team (internal).

2. STACK AND DEPLOY ROUTE
----------------------------------------------------------------
Language / framework: Next.js (App Router, edge runtime), TypeScript,
                      @cloudflare/next-on-pages
Hosting             : Cloudflare Pages (NOT the Hostinger default) - project
                      gershon-company (production, bound to
                      company.gershoncrm.com) plus a mirror project
                      gershoncrm-company kept in sync.
DNS / registrar     : Tierra.net; Cloudflare for CDN/DNS/SSL
Deploy method       : GitHub Actions (.github/workflows/deploy.yml) on push
                      to main: bumps the patch version and commits it back
                      with [skip ci], runs next-on-pages, deploys to both
                      Pages projects with wrangler.
Default branch      : main
How to ship a change: merge a PR to main. The CI version-bump commit lands on
                      main afterwards, so rebase open branches before merging.
Secrets / env vars  : GitHub: CLOUDFLARE_API_TOKEN, CLOUDFLARE_ACCOUNT_ID,
                      REPORT_TRIGGER_KEY. KV SETTINGS (edited on /settings):
                      STREAK_API_KEY, STREAK_PIPELINE_KEY, RESEND_API_KEY,
                      REPORT_FROM, REPORT_TO, REPORT_TRIGGER_KEY.
                      Values live in 1Password.
