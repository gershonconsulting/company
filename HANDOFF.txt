0. WHAT THIS REPO IS
----------------------------------------------------------------
Next.js 15 + Tailwind 4 app: Streak pipeline tracking, objectives
and monthly analytics. Live at company.gershonCRM.com.
Deploy route: GitHub Actions (.github/workflows/deploy.yml) on every
push to main. It auto-bumps the patch version, builds with
@cloudflare/next-on-pages and deploys to the Cloudflare Pages
projects gershon-company (production, company.gershoncrm.com) and
gershoncrm-company (mirror). Branches are NOT deployed, so there is
no pages.dev test link for a branch.
Settings + users live in the SETTINGS KV namespace (wrangler.jsonc).
Version shown in the sidebar comes from package.json (lib/version.ts).
